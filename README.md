# 无线通信算法数学工具库

这是一个面向无线通信研究的数学知识库，用于阅读论文、推导公式和设计算法。笔记重在回答三个问题：**这个数学工具长什么样、能解决什么问题、为什么能这样用。** 涉及无线通信时，还会展示从实际优化问题到标准数学形式的关键变换。

## 从哪里开始

先打开 [数学工具检索索引](index.md)，按学科、算法问题或常见表达式寻找笔记。也可以直接在 Obsidian 中搜索中文术语、英文别名或标签。

例如，遇到 $\frac{\mathbf x^H A\mathbf x}{\mathbf x^H B\mathbf x}$，可查阅 [广义瑞利商](线性代数/广义瑞利商.md)；遇到 $W=ww^H$ 和秩一约束，可查阅 [半正定松弛](最优化方法/半正定松弛.md)。查到工具后，应先检查适用条件，再使用结论。

本地直接以“数学工具库”文件夹作为仓库根目录和 Obsidian 知识库打开。

学科目录与笔记以中文命名，便于快速查找；英文数学术语和缩写保存在笔记顶部 YAML 的 `aliases` 中，便于对照英文文献。`tags` 用于按概念和应用场景检索。索引中的“待补充”表示该方向尚未建立笔记。

## 公式与链接

本库默认允许复数向量与矩阵：$A^H$ 表示共轭转置，$A^T$ 表示转置，$I_n$ 是 $n$ 阶单位矩阵；$A\succeq0$ 和 $A\succ0$ 分别表示 Hermitian 半正定和正定。各笔记会说明额外假设及局部符号。

笔记使用标准 Markdown 链接，行内公式用 `$...$`，独立公式用 `$$...$$`，兼容 GitHub 与 Obsidian。若新建笔记，可从 [math-tool 模板](templates/math-tool.md) 起步。

## 如何维护

新增知识时，先在 [索引](index.md) 中查找是否已有相关笔记；优先补充已有内容，确有独立主题再新增文件。新增、重命名或移动笔记时需要同步检查索引和内部链接。

**详细的写作风格、数学核查、命名和 Git 规则只在 [AGENTS.md](AGENTS.md) 维护。** 本 README 只介绍如何使用知识库，不重复维护规范。
